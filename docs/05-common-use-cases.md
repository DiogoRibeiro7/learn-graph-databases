# Common use cases

## Social graph
Users, follows, likes, communities.

## Fraud detection
Accounts, cards, devices, IPs, addresses, suspicious clusters.

## Recommendation systems
Users, products, clicks, purchases, genres, similarity.

## Supply chains
Suppliers, factories, components, shipments, bottlenecks.

## Access control
Users, roles, permissions, resources.

## Knowledge graphs
Entities and facts connected by semantically meaningful relationships.

A useful teaching pattern is to begin with a movie graph, then move to fraud detection.
